# HW01 Requirements Checklist
Exercise: HW01-AI — QA/QC Jobs · 20 Defects · Test a Physical Product
Total: 100 points | Duration: ~5 hours

---

## ⚠️ DO FIRST — Must NOT use AI (anti-cheat artifacts)
- [ ] ⚠️ **Device photo** — photo of chosen household device + student ID card in same frame (.jpg)
- [ ] ⚠️ **Job posting screenshots** — 10 screenshots, each showing your login/username on the platform
- [ ] ⚠️ **Execution videos** — ≥ 5 videos (≤ 60s each) with your own voice narration, uploaded to YouTube Unlisted
- [ ] ⚠️ **Prompt log** — real timestamps logged in `report/appendix_A_prompt_log.md` for every AI prompt sent

---

## Requirement 1 — QA/QC Job Market 2026+ (40 pts)
- [ ] Find 10 QA/QC job postings published within 60 days of submission date
  - [ ] ≥ 3 positions requiring AI/LLM/automation-AI skills (mandatory)
- [ ] For each posting include:
  - [ ] Link to the posting
  - [ ] Dated screenshot (showing your account name/login)
  - [ ] Job description summary
  - [ ] Required skills
  - [ ] Salary (if listed)
  - [ ] 1–2 sentence "AI Impact Analysis"
- [ ] QA/QC role mindmap (PNG or Markdown) — AI-generated, then find 3 mistakes in it

---

## Requirement 2 — 20 Software Defects 2022–2026 (20 pts)
- [ ] Find 20 software defects publicized between 2022 and 2026
  - [ ] ≥ 5 defects related to AI/LLM (hallucination, prompt injection, bias) (mandatory)
- [ ] For each defect include:
  - [ ] Source link
  - [ ] Description
  - [ ] Severity
  - [ ] Consequences
  - [ ] Solution/fix
  - [ ] ⚠️ 1 instance of AI bias or hallucination found when explaining THIS defect (required for ALL 20)

---

## Requirement 3 — Test Cases for ONE Physical Product (40 pts → 25 pts in rubric)
- [ ] Choose a specific household device (fan / water filter / rice cooker / smart bulb / etc.)
- [ ] ⚠️ Submit photo of device + student ID card in same frame
- [ ] Declare: brand, model, year, serial number (mask middle 4 chars)
- [ ] Design 15 test cases (Objective / Input / Steps / Expected / Actual / Verdict)
  - [ ] ≥ 3 test cases are edge cases the AI could NOT find (mandatory)
    - [ ] Screenshot of AI conversation proving AI did NOT generate these
    - [ ] Written explanation of why AI missed them
- [ ] Execute ≥ 5 test cases on the real device
  - [ ] Record ≥ 5 videos (≤ 60s each) with voice narration → YouTube Unlisted
  - [ ] Aim to find ≥ 5 defects during execution
- [ ] Log all defects found as GitHub Issues (screenshot of Issues page with your username)

---

## AI Compliance (15 pts)

### AI-1 — AI Audit Report [AI-02] (8 pts)
- [ ] Entry for each AI-generated artifact batch (mindmap, test cases, defect analysis, etc.)
  - [ ] Each entry has all 5 sections: Prompt+Tool / AI Output / Verdict / Reasoning / Student Fix
  - [ ] Timestamps on all prompts
- [ ] Summary at end: VALID/INVALID/INCOMPLETE percentages + conclusion

### AI-2 — AI Critique + Disclosure (4 pts)
- [ ] AI Critique: 200–300 words (use `/ai-critique`)
- [ ] AI-03 Disclosure Form signed and attached

### AI-3 — Checklist + Anti-cheat (3 pts)
- [ ] AI-05 Privacy & Responsible Use Checklist signed and attached
- [ ] All anti-cheat artifacts present (photo, videos, screenshots, prompt log)

### Week 1 Special (one-time)
- [ ] AI-06 Student Acknowledgement signed (required before ANY HW is graded)
